# ton-amie-zoza 2.0
زوزا: صديقة ذكية بوجه بشري (حركة شفاه ورأس وعيون) تعلّمك الفرنسية بالحوار الصوتي.

- `index.html` : التطبيق كاملاً (وجه بشري متحرك + محادثة صوتية حرّة + 19 موضوعًا + ألغاز ونكت وألسنة معقودة + تصحيح فوري).
- `data/talk.json` : مواضيع الحوار والنكت والحكم (قابلة للتعديل).
- `zoza-worker.js` : العقل الذكي (Claude) على Cloudflare Workers؛ ضع رابطه في `AI_URL` داخل index.html أو من زر ⚙️.

افتح الموقع عبر https أو localhost كي يعمل الميكروفون. يُفضَّل Chrome.
